# Task 09: dash-claim-supervised-device

## Summary

Add dashboard UI for claiming a supervision code and creating a supervised device.

## Type

⚡ Parallel | 📦 Safe to ship

## Dependencies

**Blocked by:** Task 04 (ClaimSupervisionCode API)
**Blocks:** Nothing

## Details

Create new dashboard UI flow for parents to claim a supervision code generated by an iOS device.

### Entry Points

1. New "Add supervised device" button in child management area
2. Or: dedicated route accessible from landing page redirect

### UI Components

#### Code Entry Screen

```
┌────────────────────────────────────────┐
│  Add Supervised Device                 │
│                                        │
│  Enter the 6-character code shown      │
│  on the device:                        │
│                                        │
│  ┌─────────────────────────────────┐   │
│  │  [A] [B] [C] [1] [2] [3]        │   │
│  └─────────────────────────────────┘   │
│                                        │
│  What should we call this person?      │
│  ┌─────────────────────────────────┐   │
│  │  Luke                           │   │
│  └─────────────────────────────────┘   │
│                                        │
│  [Cancel]              [Add Device]    │
└────────────────────────────────────────┘
```

#### Success Screen

```
┌────────────────────────────────────────┐
│  ✓ Device Added                        │
│                                        │
│  Luke's iPhone 14 has been added.      │
│                                        │
│  Next steps:                           │
│  1. Download Gertrude Supervise        │
│  2. Connect Luke's iPhone via USB      │
│  3. Follow the supervision steps       │
│                                        │
│  [Download for Mac] [Download for Win] │
│                                        │
│  [Done]                                │
└────────────────────────────────────────┘
```

### API Integration

- Call `ClaimSupervisionCode` with code + name
- Handle errors: invalid code, expired, already claimed
- On success, show next steps

### Files to Create/Modify

- `web/dash/app/routes/` - New route for claim flow
- `web/dash/app/components/` - Code entry component
- Navigation/menu updates to access this feature

### Notes

- Consider: should this be a modal or full page?
- The supervision tool download links should be prominent
- This is additive UI - doesn't change existing flows
