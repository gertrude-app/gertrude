{% .lead .mb-12 %} **TL;DR:** Gertrude can now _notify you by email, text, or Slack_ when
important security events happen — like password changes, login attempts, filter
suspensions, and more. Especially useful if you have ~~naughty~~ _creative_ kids.

{% image src="security-event-text.png" noBorder=true caption="Get notifications like these for your Gertrude account" /%}

## What's a security event?

A "security event" is anything that happens in the Gertrude Mac app or parents' website
that _could_ affect the safety of your child's device — things like filter suspensions,
password resets, changes to monitoring settings, or login attempts. Most of the time these
are perfectly normal actions taken by you, the parent. But if you _weren't_ the one who
did it, you'd want to know.

## How to set it up

Head to your [notification settings](https://parents.gertrude.app/settings) and add a new
notification with the **Security events** trigger. You can be notified by email, text, or
Slack — so you'll know right away if something happens, without having to remember to
check. If you have a tech-savvy child who might try to work around their protections,
these notifications give you peace of mind that you'll know about it.

{% image src="security-events-notification.png" caption="Add a notification with the Security events trigger" /%}

## Choose your notification level

Not every security event is equally urgent. To help you get the right amount of
information without being overwhelmed, there are **three notification levels:**

- **Recommended** — only the highest-risk events, like password changes, or a filter
  suspension being granted by use of the computer admin password (which can happen if your
  child learns your admin password). This is a great default for most parents.
- **Medium** — includes everything in Recommended, plus events like failed login attempts,
  system time zone changes, and remote filter suspensions.
- **All** — every recorded security event, including lower-risk items. Usually not
  necessary, but if you want to be notified about everything, this is the option for you.

{% image src="security-events-notification-level.png" caption="Choose the level of security events you want to be notified about" /%}

## Security events feed

You can always review a full history of recent security events from the
[Security](https://parents.gertrude.app/security-events) tab on the parents' website. Each
event shows a colored severity indicator so you can quickly spot the most important items
at a glance.
